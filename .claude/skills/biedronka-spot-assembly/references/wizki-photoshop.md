# Обробка візок (вікізок від агенції) скриптом Photoshop

Агенція надсилає візки (візуалізації продуктів: JPG/PNG/TIFF, іноді з PSD) як архіви transfernow. Користувач зберігає їх у `client`, розпаковує й обробляє скриптом Photoshop; результат (PSD із маскою в смарт-об'єкті) імпортується в AE (кнопка PSD, `import_psd_products.jsx`) і йде у візку (`dmp`).

## Структура в `client`
Корінь `client` залежить від шоу (підтверджено користувачем 2026-09-30):
- REG (регуляр): `X:\BiedronkaPricesOnGoing2026_231510\client\NISKIE CENY`
- FRESH: `X:\BiedronkaPricesOnGoing2026_231510\client\FRESH`
- фестивалі (FN/FW): `X:\BiedronkaZawszeNiskieCeny2026_232084\client`

Усередині кореня: `YYYYMMDD_WIZKI\<назва планші>\`. Дата = день завантаження. Підпапка `HHMM` (час завантаження) стосується лише цінівок (`YYYYMMDD_CENOWKI\HHMM\`); цінівки поки що завантажує сам користувач, я їх не качаю. Не візок (уточнення користувача 2026-09-30); `HHMM`-папки у старих `_WIZKI` (напр. `1743`, `1255`) — не схема, для нових завантажень я так не називаю. У підпапці лежить завантажений архів (`TransferNow-….zip`) і файли, вийняті з нього (іноді у вкладеній папці `TransferNow-<id>\`). Приклад: `…\NISKIE CENY\20260930_WIZKI\Makaron\`.

## Скрипт
`C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\ps_path_mask_script.js` (меню File > Scripts). Питає папку через `Folder.selectDialog` і обробляє файли `png/jpg/jpeg/tif/tiff` цієї папки (без вкладених):
1. Є path у файлі: останній path → виділення → маска шару (Reveal Selection).
2. Path нема: альфа-канал → маска; або прозорість шару (PNG) без маски; або (немає й того) `Select Subject` (хмарний режим, з фолбеком на локальний).
3. Шар з маскою загортається в смарт-об'єкт, полотно обрізається по масці (`CROP_PADDING = 0`).
4. Зберігає `<ім'я>.psd` поруч з оригіналом.
5. Проблемні файли (ERROR) і після `Select Subject` лишає відкритими для перевірки; вже відкриті пропускає.

## Що вважати необробленим
Зображення без PSD з таким самим ім'ям у тій самій папці. Виняток: користувач іноді перейменовує PSD (наприклад `206820b_topchips_papryka.psd` до `206820b.jpg`), тоді збіг за ім'ям не працює, дивись вручну. Станом на 30.09.2026 необробленими виглядають: `20260928_WIZKI\Ser` (2 jpg), `20260925_WIZKI\1340` (перейменовані PSD, скоріш за все оброблено), `20260921_WIZKI\1608\TransferNow-…` (1 jpg).

## Мої дії (домовленості)
- Без команди нічого не запускаю й не качаю. Завантаження з лінків таблиці: лише після «так» з назвою, джерелом і розміром (капчі та погодження умов робить користувач).
- Запуск скрипта Photoshop сам: окремого Photoshop MCP нема. Можливий шлях: копія скрипта в scratchpad із заданою папкою замість діалогу та запуск Photoshop з цим файлом; не перевірено, тільки за командою користувача й без зміни оригіналу скрипта.
